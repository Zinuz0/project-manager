how do i implement authorization for the different roles in the project?
1. you can implement authorization for different roles in the project by creating middleware functions that check the user's role before allowing access to certain routes or actions. For example, you can create a middleware function called `authorizeRole` that takes in the required role(s) as parameters and checks if the authenticated user has the necessary role to perform the action. If the user does not have the required role, you can return a 403 Forbidden response. You can then apply this middleware to your routes that require specific roles, such as adding members, assigning tasks, or managing the project.
2. In your project controller, you can check the user's role before performing actions like adding members or assigning tasks. For example, when adding a member, you can check if the user is an OWNER or ADMIN before allowing them to add a new member. If the user does not have the required role, you can return a 403 Forbidden response.
